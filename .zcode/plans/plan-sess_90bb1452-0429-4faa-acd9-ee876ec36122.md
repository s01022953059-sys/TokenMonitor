## 社区 TOP10 排名动态变化表 — 条形图赛道动画

### 数据层：VPS 每日快照归档

**VPS 中继新增定时归档** (`community_relay/main.go`)：
- 新增 `/v1/archive` 端点：把当天所有报告聚合为 TOP10 快照（`{date, leaderboard: [{id, display_name, tokens, tool}]}`），写入 GitCode `community-data` 分支 `community/archive/{date}.json`
- 用 systemd timer 或 Go 内置 ticker 每天 23:55 触发一次归档
- 归档是幂等的（同一天重复归档只覆盖）

**客户端新增 API** (`server.py` + `community.py`)：
- `GET /api/community/history` — 从 GitCode 读取 `community/archive/` 目录，返回最近 N 天的快照列表
- 客户端无需 GitCode token，走 VPS 中继或直接读公开的 community-data 分支

**Go 端镜像** (`go_build/community.go`)：
- 同步实现 `/api/community/history`

### 前端层：条形图赛道动画

**入口** (`index.html` + `go_build/static/index.html`)：
- 社区排行榜标题栏新增"排名变化"链接按钮，点击打开新的弹窗 `#rankHistoryModal`
- 弹窗结构：日期轴控制（◀ 日期 ▶ + 播放按钮）+ 条形图赛道区域

**赛道动画**（纯 CSS/JS，无外部库）：
- 每行：排名序号 + 用户名 + 横向条形（宽度=token占比）+ 数字
- 切换日期时：行用 CSS `transition: transform` 平滑移动到新位置（`order` + `translateY`）
- 数字用 `requestAnimationFrame` 滚动增长/减少
- 自动播放模式：每 2 秒切一天，循环播放

**数据获取**：
- 打开弹窗时 fetch `/api/community/history` 获取所有快照
- 前端缓存到 localStorage（当天有效）

- 重启 systemd 服务
