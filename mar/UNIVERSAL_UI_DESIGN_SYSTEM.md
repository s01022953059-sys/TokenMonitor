# 通用 UI 设计与一致性验收规范

目标是清晰、可访问、稳定和可验证。布局、配色和组件遵循产品场景，不强制毛玻璃、固定颜色、像素高度或不换行。UI-01 至 UI-08 是稳定验收编号，见 [规则目录](rules/catalog.json)。

## UI-01 设计变量与共享组件

项目维护唯一设计变量来源：颜色语义、字体、间距、圆角、阴影、动效和层级。新页面复用共享组件，差异有明确场景与例外；主题/品牌/平台差异通过映射表达，不机械要求最终像素相同。

验收：组件清单、变量来源/版本、页面到组件和变量的映射；项目 lint/组件测试及浏览器计算样式或组件快照。截图基线变更独立审阅，不遇到差异就自动更新基线。

## UI-02 响应式与内容可达

核心对象、状态和主操作清晰；渐进信息支持键盘与触控，不只提供 hover/title。工具栏允许折叠、换行或收纳，不为单行截断功能；二维表格等按范围记录例外。

验收：支持的视口、长文本、语言、200% 与 400% 缩放；适用 Web 页面检查等效 320 CSS px 宽下功能可达。不笼统宣称所有屏幕通过。

## UI-03 键盘、焦点与模态

控件有可访问名称、可见焦点和合理顺序；模态语义、焦点进入/约束/返回正确，按场景支持 Escape，保护未保存输入。长内容下关闭与主操作可达，背景滚动控制不破坏内部触控、键盘或缩放。

验收：真实浏览器/目标客户端键盘导航、打开关闭、焦点返回、长内容与滚动测试，结合自动无障碍检查和关键人工辅助技术检查。

## UI-04 状态反馈与错误恢复

loading、empty、success、error、disabled、offline 等适用状态保持一致语义；防重复提交、失败保留输入并提供恢复路径。状态不只依赖颜色或动效；普通成功可非阻断，错误和高影响结果保留可感知文本，支持减少动效。

验收：适用状态、慢请求、失败、重试和重复操作；对比度、辅助技术状态播报与信息停留时间，不能以截图颜色相似代替状态正确。

## UI-05 权限、只读与来源

只读数据明确状态和来源；允许语义正确的 readonly 控件用于复制或辅助技术。禁用操作给出可访问原因，服务端仍校验权限、资源及业务状态；点击后网络/权限变化仍应处理错误。

验收：只读交互、权限变化与直接请求服务端的拒绝行为；生产测试接口隔离见 [安全边界](docs/SECURITY.md)。

## UI-06 高影响操作与状态真实性

删除、覆盖、批量修改预览具体对象与影响，按风险提供确认、撤销或恢复，低风险操作不强制双重弹窗。父级变化不能伪造子项测试、审核或验收结果；业务级联明确字段、条件、范围与恢复，保留原始验证记录。

验收：未验收子项、部分失败、父级重开、撤销、重复点击与并发修改，保持状态和证据一致。

## UI-07 运行态与视觉回归

页面/组件清单定义覆盖范围，验证路由、布局、交互与平台差异。Node VM 不替代浏览器与原生客户端。截图固定视口、主题、字体和数据；记录基线与差异原因，阈值/动态屏蔽有依据，不能靠提高容差掩盖回归。

验收：关键旅程运行态、组件状态截图、无障碍及真实平台证据分别提供，缺目标平台标记未验证。

## UI-08 覆盖与受控例外

全部 UI 规则逐项报告 passed、failed、not_run、not_applicable 或 exception。未通过/未执行不能就绪；不适用也需理由与批准依据。例外记录规则、页面/组件、理由、风险、补偿措施、批准人、可信批准记录与到期日，仅覆盖该范围。

验收：填写 [UI 报告模板](templates/ui-report.json)，用 [校验器](tools/check_ui_report.py) 检查覆盖、版本、证据路径与摘要。证据由项目可信测试过程采集并核实内容；格式通过仅说明材料结构完整。

## 可选交互模式

| 模式 | 适用条件 | 保留能力 |
| --- | --- | --- |
| 头部/内容/操作区模态 | 长内容和主操作 | 焦点管理、缩放、操作可达 |
| Chip 多选 | 有限候选集 | 键盘、搜索与合法新增需求 |
| 最小差异比较 | 长文本审阅 | 来源、完整上下文、非颜色标记 |
| 非阻断成功反馈 | 低风险重复操作 | 可访问播报、失败持久提示 |

对照：[W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、[WAI 模态模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。采用本规范不代表取得无障碍认证。
